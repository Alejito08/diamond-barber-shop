La pagina esta hecha solamente con HTML y CSS.

PARA PROBARLA:
1. Descomprime la carpeta.
2. Abre index.html en el navegador.

PARA GITHUB:
1. Crea un repositorio.
2. Sube index.html, estilos.css y la carpeta imagenes.
3. Haz commit y push.

PARA RENDER:
- Crea un servicio "Static Site".
- Conecta el repositorio de GitHub.
- Build Command: dejar vacio.
- Publish Directory: .
- Guarda y despliega.
